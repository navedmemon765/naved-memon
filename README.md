# Naved Memon — Creative Portfolio

A responsive, animated React + Vite portfolio for digital marketing, creative strategy, paid ads, and short-form video editing.

## Deploy free with Vercel
1. Open https://vercel.com/new and sign in with GitHub.
2. Import `navedmemon765/naved-memon`.
3. Keep the framework as Vite, build command `npm run build`, and output directory `dist`.
4. Click Deploy. Vercel will give you a live `*.vercel.app` URL.

## Run locally
Install Node.js LTS, then run `npm install` and `npm run dev`.

## Before publishing
Review all dates and claims, add real portfolio samples when available, and replace the generic Instagram link in `src/main.jsx` with your profile URL.
